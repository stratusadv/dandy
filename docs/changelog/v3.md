# Changelog

## v3.0.0

A breaking, structure-focused release: the package was physically reorganized into a
four-layer, domain-driven design with an enforced dependency model. Behavior, the
public API, and configuration semantics are unchanged; internal import paths are not.
See the [migration guide](../migration/v2_to_v3.md) for the old-to-new map.

### Restructured (breaking)

- The flat 2.x layout (`dandy/bot`, `dandy/llm`, `dandy/intel`, `dandy/core`,
  `dandy/http`, `dandy/file`, `dandy/cache`, `dandy/recorder`, `dandy/conf`,
  `dandy/cli`) is now:
  - `dandy/domain/` — entities, value objects, and rules (Intel, Prompt, Message,
    LlmOptions, tool descriptors, token estimation, decoder values)
  - `dandy/application/` — use cases (Bot, the LLM / tool / decoder / diligence
    services, and the coding agent)
  - `dandy/infrastructure/` — adapters (LLM connector and config, HTTP, file,
    cache, recorder, futures)
  - `dandy/interfaces/` — the CLI (REPL, TUI, entry point)
  - `dandy/shared/` — the shared kernel (service/connector bases, exceptions,
    settings, files, media, typing, constants)
- All internal import paths changed accordingly. The `dandy` root re-exports
  (the public API) are unchanged.

### Added

- Architecture enforcement with import-linter: six contracts in `pyproject.toml`,
  a `just lint-imports` recipe, and an "Architecture Tests" step in CI. Cross-layer
  imports outside the documented seams now fail the build.
- A documentation site rebuilt from the ground up around the domain model:
  ubiquitous language, bounded contexts, tactical patterns, architecture,
  getting started, a concept-by-concept user guide, and a per-layer API reference
  (mkdocs + Material + mkdocstrings).

### Removed

- `dandy/core/` (split into the shared kernel and the infrastructure layer).
- The one-line re-export shims in `dandy/infrastructure/file/`
  (`utils.py`, `exceptions.py`, and the `audio/` / `image/` subpackages); the real
  implementations live in `dandy/shared/files.py` and `dandy/shared/media.py`.
- The old tutorial-based docs tree and the heavyweight `documentation` extra,
  replaced by a slim one (`mkdocs`, `mkdocs-material`, `mkdocstrings[python]`).

### Changed

- Version bumped to 3.0.0 (`dandy.shared.constants.__VERSION__`).
- Tests reorganized to mirror the new layout (`tests/domain/`,
  `tests/application/`, `tests/infrastructure/`, `tests/interfaces/`,
  `tests/shared/`).
