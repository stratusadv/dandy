# 2026 Roadmap

Re-marked against **v3.0.0a1** (pre-alpha, the current release state) as of
2026-11-05. The original 2026 plan was written during the v2 era; the statuses below
reflect what the v3.0.0a1 code actually ships, and the November and December plans
were set on 2026-11-05.

## Legend

- 📖 = Planning
- 🚧 = In Progress
- ✅ = Complete
- 🚫 = Problem

## January

- v2 Alpha Release ✅
- v3.0.0a1 — the v3 rewrite (DDD layering, agents, skills, tool calling) is now the
  main line and ships as a pre-alpha ✅

## February

- v2 Stable Release ✅

## March

- Command Line Interface Prototype ✅ (shipped, and since reworked: the CLI is now a
  pure agent REPL with sessions — [The CLI Agent](../user_guide/cli_agent.md))

## April

- Full OpenAI Options Support ✅ ([`LlmOptions`](../reference/domain.md) mirrors the
  OpenAI chat-completion parameters; set them per config in `OPTIONS`)

## May

- Documentation Update ✅ (the v3 docs site is fully rewritten — 45 pages, including
  the roadmap, about, and the ported archived content)

## June

- File System Control ✅ (agent file tools: read, write, edit, delete, create
  directory, list — [Tool Calling](../user_guide/tool_calling.md); the
  `FileService` adapter for general file work)
- Llm Vision Service Update ✅ (multimodal `prompt_to_intel` accepts image
  URLs, file paths, and base64 strings)
- Llm Listening Service Update ✅ (multimodal `prompt_to_intel` accepts audio
  URLs, file paths, and base64 strings)
- Bots Calling Bots ✅ ([the Example Project](../user_guide/example_project.md) is a
  standing reference: ten-plus bots orchestrated through one accumulator Intel)
- Stateful Memory ✅ (agent sessions: `save_session` / `load_session`,
  `SessionStore`, CLI auto-save and `--continue`)

## July

- Database Connector 📖
- Cache Improved ✅ (v3 caching: `MemoryCache` / `SqliteCache` plus the
  `cache_to_memory` / `cache_to_sqlite` decorators — [Caching](../user_guide/caching.md))

## August

- Full Error / Exception Handling ✅ ([Critical/Recoverable hierarchy](../user_guide/error_handling.md)
  with per-subsystem exceptions and the validation/HTTP/decision retry loops)
- Data Compaction ✅ (calibrated token estimation plus `compact_message_history`,
  which keeps every agent turn and tool loop inside the context window)

## September

- Enterprise Controls 📖
- Data Encoding 📖

## October

- Full Type Handling 🚧 (typed Intel schemas, typed tool parameters, and typed
  skill-method signatures are in; end-to-end runtime typing across the whole stack is
  not yet complete)
- Data Enrichment 📖

## November

- Recorder Improved to Support Complex Execution ✅ (the v3 recorder captures the
  agent/tool-loop event stream, not just bot round trips, and renders it to
  HTML/JSON/Markdown — [Recording](../user_guide/recording.md))
- v3.0.0 Beta 📖 — the first beta cut out of the pre-alpha, once the docs, the
  remaining type-handling work, and the database connector land
- Full Type Handling 🚧 (carried from October — end-to-end runtime typing across
  the whole stack)
- Database Connector 📖 (carried from July — a first-class persistence adapter for
  Intel and agent sessions, beyond the caching-focused `SqliteCache`)
- Data Enrichment 📖 (carried from October)

## December

- v3.0.0 Stable Release 📖 — the year-end target, out of the November beta
- Prompting Improved 📖
- Enterprise Controls 📖 (carried from September)
- Data Encoding 📖 (carried from September)
